# Ironhold

A desktop theme for Ubuntu (GNOME) and Windows 10/11, inspired by high-fantasy RTS games. It uses
forged iron, carved stone, gilded trim, war banners and runes. All artwork is original and generated
procedurally from code. The theme uses no game assets, logos or trademarks.

| Variant | Look |
|---|---|
| **Crown** | Blue and gold, polished steel, kite shield and sword crest, moonlit citadel |
| **Ember** | Red and black, dark iron and bronze, spiked shield and crossed axes, burning sky |

## What you get

| Part | Ubuntu / GNOME | Windows |
|---|---|---|
| App theme | GTK 3 theme + libadwaita/GTK 4 recolor | Dark mode + accent color |
| Desktop shell | GNOME Shell theme (panel, menus, dash, notifications, dialogs, lock screen) | - |
| Cursors | Xcursor theme, 13 cursors + ~100 aliases, animated wait/progress | `.cur` / `.ani` scheme, 32-128 px |
| Icons | Folders, home, trash, start-here (inherits Yaru for everything else) | `.ico` folder icons |
| Wallpapers | 2 per variant, 4K, registered in Settings > Appearance | Same, plus a slideshow |
| Sounds | freedesktop sound theme, 19 events + aliases | Sound scheme for 21 system events |
| Extras | - | Windows Terminal color scheme |

## Using official Warcraft / WoW art (personal use)

Ironhold ships only original artwork. To use official wallpapers you've downloaded on your own
desktop, put them in `local-art/` (see `local-art/README.md`):

```bash
cp ~/Downloads/some-official-wallpaper.jpg local-art/Crown/
python3 build.py --variant Crown && ./install.sh Crown       # your image becomes the default wallpaper

# Or create a variant whose colors are sampled from the artwork:
python3 variant_from_art.py local-art/Stormwind/*.jpg --name Stormwind --base Crown
python3 build.py --variant Stormwind && ./install.sh Stormwind
```

`variant_from_art.py` picks the dominant gold/bronze tone for the trim, the strongest banner
color for the accent, and the darkest area's hue for the backgrounds. It then adjusts the colors
until text and trim meet a minimum contrast. A swatch preview is saved to `dist/previews/`.

`local-art/` is git-ignored. Builds that include your images copy them into `dist/`, so don't
share `dist/` or the Windows pack built from it. Blizzard's artwork stays theirs; check Blizzard's
fan content policy before publishing anything that contains it.

## The look

The theme borrows the *feel* of a high-fantasy RTS interface, not its actual assets. Everything
below is original and generated by `lib/art.py`:

- Gilded filigree frames with corner gems on menus, popovers, tooltips and Shell dialogs
- Tileable stone textures on title bars, sidebars and the top panel; leather on primary buttons;
  parchment on tooltips
- Painted, moonlit or fire-lit clouds on the citadel wallpapers
- [Cinzel](https://fonts.google.com/specimen/Cinzel) (SIL Open Font License, in `fonts/`) for
  window titles, headings, the panel and the lock-screen clock

## Sounds

The sounds are synthesized in `lib/sound.py`, so there are no recorded samples or licensing to worry about.

- **Crown** uses cathedral bells and brass fanfares. For example, a horn call plays at login and a
  sword is drawn when you plug in a USB device.
- **Ember** uses war drums, gongs and a gritty war horn. For example, drums and a horn play at
  login and fire crackles when you empty the trash.

To preview the sounds, play the files in `dist/linux/sounds/Ironhold-*/stereo/`. To retune a
variant, change `sound.root` in `config.json`, or edit the event recipes in `crown()` and `ember()`.

On Windows 10/11, the startup sound can't be changed by a theme, and the logon and logoff sounds
only play if those events are enabled.

## Build

You only need Python 3 and the system librsvg/cairo libraries, which come with every GNOME desktop.
No pip packages are required.

```bash
python3 build.py              # both variants -> dist/
python3 build.py --fast       # 1080p wallpapers, fewer cursor sizes
python3 build.py --variant Ember --only cursors
```

## Install on Ubuntu

```bash
./install.sh            # installs and applies Crown
./install.sh Ember      # installs and applies Ember
./install.sh --uninstall
```

The shell theme needs the **User Themes** extension (`sudo apt install gnome-shell-extensions`,
then log out and back in). The installer backs up any existing `~/.config/gtk-4.0/gtk.css` and
restores it when you uninstall.

## Install on Windows

1. Copy `dist/windows/Ironhold-Crown` (or `-Ember`) to the Windows PC.
2. In that folder, run `powershell -ExecutionPolicy Bypass -File .\install.ps1`.

This installs for the current user only and needs no admin rights. It applies the wallpaper, accent
color, dark mode, cursor scheme and sound scheme. To remove it, run `install.ps1 -Uninstall`.

To use the folder icons, open a folder's Properties > Customize > Change Icon and pick a file
from `Icons\`. To add the Windows Terminal colors, paste `windows-terminal-scheme.json` into the
`schemes` list in your Terminal `settings.json`.

Windows does not officially support restyling window frames or the taskbar. If you want that,
use [Windhawk](https://windhawk.net) mods or a third-party `.msstyles` visual style. Those tools
patch the system, so use them at your own risk.

## Customizing

- **Colors:** edit `config.json`. Every stylesheet, icon, cursor and wallpaper is regenerated from it.
- **New variant:** add a block under `variants` in `config.json`.
- **Artwork:** `lib/art.py`. **Stylesheets:** `src/*/*.css.in`, where `{{key}}` inserts a palette
  color and `{{key,0.4}}` inserts it as `rgba()` with that alpha.
- **Rename the theme:** change `name` in `config.json` and `NAME` in `install.sh`.

## Layout

```
config.json          palettes for each variant
build.py             builds dist/linux and dist/windows
install.sh           Ubuntu installer (per user)
lib/art.py           procedural SVG art: cursors, icons, emblems, wallpapers
lib/raster.py        SVG -> PNG/pixels via system librsvg (ctypes)
lib/cursorfmt.py     Xcursor, .cur, .ani and .ico writers
lib/sound.py         procedural sound synthesis (bells, horns, drums, blades)
lib/palette.py       palette extraction from artwork (gdk-pixbuf + k-means)
variant_from_art.py  creates a variant from your images
local-art/           your personal artwork (git-ignored)
fonts/               Cinzel (OFL)
src/gtk-3.0, src/gtk-4.0, src/gnome-shell   stylesheet templates
src/windows/install.ps1                     Windows installer
```
